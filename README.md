# PoleSight

Supplementary material for **"PoleSight: A Benchmark Dataset and Scalable
Range-Image Generation Framework for Utility Pole Detection."**

PoleSight is a range-image instance-segmentation dataset for pole-like roadside
infrastructure — **1,088 range images** with **6,121 polygon instances** across
four pole classes, generated by spherical projection from mobile laser scanning
point clouds collected on public roads in Finland.

---

## ➡️ The release is on the [`dataset`](../../tree/dataset) branch

This branch is the working history and does **not** contain the released
dataset. Everything the paper refers to — the images, the annotations, the
evaluation records, and the scripts that reproduce them — lives on `dataset`:

```bash
git clone -b dataset https://github.com/akashshingha850/polesight.git polesight
```

Or browse it at
**<https://github.com/akashshingha850/polesight/tree/dataset>**.

## The dataset at a glance

| | |
|---|---|
| Frames | 1,088 — 1,059 annotated, 29 background negatives |
| Instances | 6,121 polygon masks |
| Split | 870 train / 109 val / 109 test |
| Image format | 1024×128 single-channel 16-bit PNG; stored value is return intensity |
| Label format | YOLO polygons, `class x1 y1 x2 y2 … xn yn`, normalized |
| Classes | `fence_pole`, `gantry_sign_pole`, `light_pole`, `traffic_pole` |

Targets are small and thin: 5,988 of 6,121 instances fall under the COCO *small*
cutoff, at a median mask of 71 px², a median box aspect ratio of h/w = 2.1, and a
mask filling only 0.35 ± 0.23 of its bounding box. That is why the dataset
carries polygon masks rather than boxes, and why mask AP is the hard metric on
it.

The `dataset` branch also ships the evaluation records behind the fifteen
published instance-segmentation baselines (YOLOv8-seg, YOLO11-seg and
YOLO26-seg, in five variants each), so every reported figure can be regenerated
without a GPU.

## What is on this branch

The development history: annotation preparation, training sweeps, and analysis
as they were run. It is kept for provenance and is not a reproduction package —
paths, configuration and layout here do not match what the paper describes. Use
the `dataset` branch for anything you intend to run or cite.
